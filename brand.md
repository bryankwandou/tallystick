# Brand — Tallystick

Verifiable settlement for autonomous agents. Every payout splits into a signed claim and an enclave-written receipt; funds move only when the halves match.

_Generated by `brand-design` skill on 2026-08-10. Update by re-running the skill._

## Palette — Kerf Line

**Vibe:** infra · technical · minimal · olive-warm black
**Category:** infra/data (tooling/dev adjacent)
**Mood:** technical + minimal

Cold-derived — no reference brand was used as an anchor. The olive-warm gray
(hue 90) is the deliberate differentiator: this category defaults to cool slate,
and the warm cast ties the palette to the physical tally stick the brand is named
for without any literal wood texture. A "kerf" is the slot a saw cuts — the split
that produces two matching halves.

### Contrast check

All 28 foreground/background pairs verified against WCAG AA in both modes.
Computed with `culori` (`wcagContrast` on converted sRGB), not estimated.

| Pair | Light | Dark | Min |
|---|---|---|---|
| foreground / background | 17.69:1 | 17.29:1 | 4.5 |
| foreground / card | 18.47:1 | 15.78:1 | 4.5 |
| muted-foreground / background | 6.54:1 | 7.10:1 | 4.5 |
| muted-foreground / card | 6.82:1 | 6.48:1 | 4.5 |
| primary-foreground / primary | 5.48:1 | 10.23:1 | 4.5 |
| destructive-foreground / destructive | 5.14:1 | 5.86:1 | 4.5 |
| primary / background | 5.32:1 | 9.44:1 | 3.0 |
| ring / background | 5.32:1 | 9.44:1 | 3.0 |
| destructive / background | 5.21:1 | 3.10:1 | 3.0 |
| border / background | 1.67:1 | 1.78:1 | 1.5 |

Two deviations from the stock derivation, both deliberate:

1. **`--border` was pushed lighter** than the reference formula (`bgL + 0.19`
   rather than `+ 0.08`). Every candidate palette failed `border/background` at
   ~1.28:1 otherwise. The design direction asked for `rgba(255,255,255,0.08)`
   hairlines, which sit below the visibility floor by design — that value now
   lives in a separate `--hairline` token for decorative rules only.
2. **`--destructive` was darkened** in dark mode (L 0.65 → 0.52). The reference's
   fixed red put near-white text at 3.39:1, under AA. Darkening it clears both
   `destructive-foreground/destructive` (5.86:1) and `destructive/background`
   (3.10:1).

### The `--hairline` token

`--hairline` is intentionally below AA. Use it only for decorative rules and the
seam motif. Never use it as the sole boundary of an interactive control or as a
divider a user must perceive — use `--border` for those.

## Typography — IBM Plex Sans + IBM Plex Mono

- **Display + body:** IBM Plex Sans (400 / 500 / 600)
- **Mono (DIDs, hashes, lamports, contract ids):** IBM Plex Mono (400 / 500)

Wired via `next/font/google` in `src/app/layout.tsx`. CSS variables `--font-sans`
and `--font-mono`, bridged into Tailwind v4 through the `@theme inline` block in
`globals.css`. Do not replace this with a `<link>` tag — `next/font` inlines the
files at build time, so there is no FOUT and no layout shift.

Chosen because Plex Sans and Plex Mono are one superfamily: DID strings and body
copy share letterform skeletons, which is the seam motif expressed in type. Geist
was rejected specifically because it is Vercel's typeface and this project already
carries a risk of reading as a Vercel clone.

### Type scale

| Role | Class | Use |

Use the `.tnum` utility (defined in `globals.css`) or `tabular-nums` on any
figure that updates in place, so digits do not jitter.

## Gradients (not used)

This palette's mood is technical + minimal, and the locked design direction
excludes gradients outright — "no gradients, no illustrations, no decorative
color" is what defines the direction. Hero gradients are also the single
most-flagged generic-AI signal. None were generated. Re-run `brand-design` if
this changes.

## Accent discipline

The accent (`--primary`, signal green) carries exactly one semantic job: it marks
**verified / settled / matched** state. The moment it appears on a control that
does not represent verification, the palette collapses into generic and the
restraint stops reading as intentional.

Allowed: settled badges, matched-halves indicators, the seam notch, focus rings,
the single primary CTA per view.
Not allowed: decorative fills, section dividers, icon tints, hover washes on
non-verification controls, gradient stops.

## Tone and voice

### Words to use

Direct, specific, number-forward, factual. Prefer verbs over adjectives and nouns
over metaphors. One sentence per idea. When describing an action, say what it does
rather than what it feels like. Lists beat paragraphs; numbers beat adjectives.

### Words to avoid

Hype words (revolutionary, game-changing, unleash, supercharge, seamless,
powerful), emoji, exclamation marks, and overpromising. "Unlock" is banned. Also
avoid words that describe effort instead of outcome — "simply", "just", "easy".
Vague aspirational headlines ("Build the future", "Scale without limits") are
disqualifying.

### Voice example

> Settled 0.25 SOL in 1.4 s. Claim and receipt matched. Signature finalized at
> slot 402,118,774.

## Usage dos and don'ts

**Do:**

- Use the CSS variables (`bg-background`, `text-foreground`, `bg-primary`)
  everywhere. Never hardcode hex in components.
- Keep the 4 px spacing grid (`gap-2`, `p-4`, `px-6`).
- Use `font-mono tabular-nums` for every DID, hash, lamport amount and contract id.
- Vary `border-radius` by component role — uniform radius everywhere is a
  flagged generic signal. `--radius` is 0.375rem (tight, technical).
- Test every component in both light and dark before calling it done.

**Don't:**

- Use `transition: all` / `transition-all`. Name the property.
- Use arbitrary Tailwind spacing values (`p-[13px]`). Stay on the grid.
- Use the accent for anything that is not verification state.
- Add a violet or blue hero gradient, or gradient text on headings.
- Build a three-column icon + heading + paragraph feature grid.
- Center everything — the direction calls for asymmetry and an offset seam.
